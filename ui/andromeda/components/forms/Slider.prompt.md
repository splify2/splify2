Параметр с границами: ползунок для быстрого движения, число рядом — для точного.

```jsx
<Field label="полуспад уровня" hint="через сколько дней вес наблюдения падает вдвое">
  <Slider value={45} min={7} max={180} step={1} unit="дней" onChange={setHalfLife} label="полуспад уровня" />
</Field>
```

- Границы — часть смысла, а не косметика: они не дают одним движением превратить расчёт в бессмыслицу. Ставьте `min`/`max` всегда.
- Единица стоит после числа отдельным словом, как везде: «45 дней», «0,25».
- Недоступный ползунок остаётся на месте с 55 % прозрачности — как и любой недоступный контрол.
