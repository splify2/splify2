Форма ряда рядом с числом — без осей и без подписей.

```jsx
<Sparkline values={[1.34, 1.33, 1.35, 1.34, 1.32, 1.36, 1.34]} reference={1.45} />
```

- Спарклайн никогда не стоит один: рядом обязательно число (`Figure`, `StatPair`) — график даёт направление, число даёт величину.
- Цвет — только accent/off/ink. Токены состояния сюда не идут: график не оценка.
- Последняя точка отмечена: читатель должен видеть, где «сейчас».
