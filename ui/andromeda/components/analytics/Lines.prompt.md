Ряды по времени одного масштаба: факт, прогноз, препрогноз, план. Наведение показывает все ряды в точке.

```jsx
<Lines labels={days} bands={weekendIdx} reference={planPerDay} referenceLabel="план в день" series={[
  { label: "факт", values: fact, tone: "accent" },
  { label: "прогноз", values: forecast, tone: "accent", dashed: true },
  { label: "препрогноз", values: premonth, tone: "off", dashed: true, width: 1.5 },
]} format={(v) => `${f1(v / 1e6)} млн`} tipFormat={(v) => `${f1(v / 1e6)} млн ₽`} />
```

- Ось Y всегда от нуля: обрезанная ось превращает шум в драму.
- Факт — сплошной акцент; всё прогнозное — пунктир; план — чернила (`reference` или ряд `ink`). Тонкий пунктир серым — «замороженная» дорожка, с которой сравнивают.
- `label` у каждого ряда обязателен, когда рядов больше одного: без него подсказка показывает безымянные числа.
- `hollow` — индексы точек, которым доверяют меньше (последний бакет «19:00+» вбирает вечерний навес); `valueLabels` — подписи над точками при ≤14 точках, потому что на телефоне наведения нет.
- `cat1…cat7` — только для наборов, где рядов заведомо несколько и все равноправны (дни недели). Второй ряд обычного графика — серый `off`.
- Число рядом с графиком должно быть той величиной, которую на графике видно глазом. Если величин две (расхождение за прошедшие дни и поправка на остаток) — показывайте две и подписывайте каждую.
- Рядов больше четырёх — это уже два графика.
