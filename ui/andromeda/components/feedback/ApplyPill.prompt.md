Изменения сохраняются сразу, а в ядро уходят по этой кнопке.

```jsx
<ApplyPill changes={diff(applied, current)} state={pill} onApply={apply} offset={118} />
```

- Считайте `changes` дифом со снимком применённого. Инкремент по клику — ошибка: он обещает работу, которой нет.
- На экранах без редактирования пилюли быть не должно вовсе.
