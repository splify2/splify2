Основная единица раскладки. Внутри карточки вложенные блоки идут на радиус 12.

```jsx
<Card heading="Подписка" meta="обновлено 12 мин назад">…</Card>
<Card tone="warn">…</Card>
```

- Тени у карточек нет — только линия. Тень означает «плавает над страницей».
- Заголовок карточки — 15/600, не крупнее: заголовок раздела уже есть выше.
- Когда заголовок и описание — разметка (перенос, значок, действие справа), используйте составные части: `<Card><CardHeader><CardTitle/><CardDescription/></CardHeader><CardContent/></Card>`. Анатомия та же, что у `heading`/`meta`.
