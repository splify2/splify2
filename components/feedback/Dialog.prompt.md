Только для необратимого: снос, остановка, удаление с роутера.

```jsx
<Dialog open={open} title="Остановить всё?" confirmLabel="Остановить"
  onConfirm={stop} onCancel={close}>
  Движок остановится, правила из ядра уйдут. Автозапуск тоже снимется — перезагрузка роутера ничего не вернёт.
</Dialog>
```

- Кнопка называет действие: «Остановить», «Удалить правило».
- Обратимое действие диалога не требует: сделайте и покажите `Toast`.
