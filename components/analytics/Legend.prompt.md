Легенда графика: образец повторяет марку на графике — столбик, линию, засечку.

```jsx
<Legend items={[
  { label: "факт", kind: "line", tone: "accent" },
  { label: "прогноз", kind: "line", tone: "accent", dashed: true },
  { label: "препрогноз", kind: "line", tone: "off", dashed: true },
  { label: "план", kind: "tick", tone: "ink" },
]} />
```

- Два ряда и больше — легенда обязательна; один ряд — не нужна, его называет заголовок карточки.
- Ряды кодируются так на всей системе: акцент — главный (факт, продажи), серый `off` — второстепенный, который не является достижением (выдача, препрогноз), чернила `ink` — план и уровни. Пунктир — всё прогнозное. Токены состояния в рядах не участвуют.
- Тоны состояния в легенде допустимы только для оценочных зон — «выше цели», «ниже — разобрать»: там цвет и есть оценка. Ряд данных состоянием не красится никогда.
- `fill: "half" | "ghost"` у столбика повторяет плотность ряда на Bars — три состояния одного показателя различаются в легенде так же, как на графике.
