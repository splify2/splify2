Таблица чисел — там, где список объектов не годится: много столбцов одинаковой природы, нужна сортировка.

```jsx
<Table sortKey={sort} onSort={setSort} minWidth={720}
  columns={[
    { key: "name", title: "сотрудник", render: (r) => <b>{r.name}</b> },
    { key: "score", title: "балл", align: "right", render: (r) => fmt2(r.score) },
    { key: "ug", title: "доля УГ", align: "right", render: (r) => `${fmt1(r.ug)} %` },
  ]}
  rows={people} rowKey={(r) => r.guid} />
```

- Числа — вправо, табличными цифрами, с единицей в заголовке или в значении, но не и там и там.
- Заголовок — строчными («доля УГ»), капс делает сам компонент.
- Ширина фиксируется `minWidth`: сжатие столбцов до нескольких букв хуже горизонтальной прокрутки, а о прокрутке компонент говорит сам.
- Объекты с действиями (изменить, выключить) — это `ListRow`, не таблица.
