# UI kit — консоль splify2 (26.9 Andromeda)

Полная рабочая консоль, собранная **только из компонентов** `components/`. Это не сторибук:
каждый экран выглядит и ведёт себя так, как должен в LuCI.

## Экраны

| Файл | Что показывает |
|---|---|
| `Console.jsx` | Оболочка: состояние, разделы, тема, `ApplyPill`, `Dialog`, `ToastStack` |
| `Rail.jsx` | Рельс разделов, знак, переключатель темы, «Остановить всё» |
| `OverviewScreen.jsx` | Вердикт, находка, трафик по правилам, остаток подписки, «куда пойдёт домен» |
| `RulesScreen.jsx` | Правила цепочкой «что → кому → куда», приоритет стрелками |
| `RuleEditorScreen.jsx` | Три колонки, каталог с поиском, устройства из аренд DHCP, ручные адреса с проверкой |
| `OutputsScreen.jsx` | Подписка, узлы с проверкой отклика, обфускация WireGuard поверх TCP |
| `CatalogScreen.jsx` | Каталог издателя, фильтр «используются», свои списки |
| `DiagnosticsScreen.jsx` | Находки, раскрытие исправных проверок, логи дословно |
| `data.js` | Данные-заглушки + `snapshot`/`countChanges` — контракт счётчика изменений |

## Что здесь проверяется на живом

- **Счётчик «Применить»** — это диф с применённым снимком. Включите тумблер и верните обратно: пилюля исчезнет.
- **Порядок правил** — стрелки реально меняют приоритет, номер строки обновляется.
- **Проверка ввода** — смешение адресов и MAC, имя вместо адреса у обфускатора, ссылка не того вида: всё называется словами до сохранения.
- **Тема** — переключатель в рельсе меняет `data-theme` на корне; цвета состояний не меняются.

## Как открыть

`index.html` грузит `.jsx` через `assets/ds-loader.js` (fetch → Babel → CommonJS) — сборка не нужна,
единственный источник правды остаётся в `.jsx`. В продакшене эти же файлы собирает обычный бандлер.
