# design/ — остальное из экспорта Andromeda

Всё, что было в архиве экспорта дизайн-системы (`Andromeda.zip`, синхронизация 2026-08-28),
но не вошло в сам пакет: прототипы и макеты (`*.dc.html`), карточки гайдлайнов, UI kit
консоли, превью, собранный IIFE-бандл `_ds_bundle.js`, манифест и метаданные синхронизации.
Лежит без изменений, чтобы экспорт можно было восстановить целиком, а не только его код.
Код пакета — на уровень выше; при расхождении правда там.
