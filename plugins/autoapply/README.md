# autoapply — автоприменение на роутере

Официальный плагин splify2 (`splify2-core-plugins`). Применяет сохранённые настройки **само, через паузу после последней
правки, даже когда страница закрыта**. До плагина это делал только браузер (Andromeda, `ui/src/lib/autoapply.ts`): закрыл
вкладку — не применилось. Пользуется платформой **только через API**
([splify2-api](https://github.com/splify2/plugin-sdk/blob/main/docs/splify2-api.md)); `s2p lint --official` и стенд
`tests/pluginhygiene.sh` отказывают плагину, который заглянет в файлы, переменные или функции каркаса.

## Что делает

| Что | Как |
|---|---|
| Спека записана — применить через паузу, подряд идущие правки одним применением | хук `post_spec_set` ставит метку и запускает отложенное применение (`bin/apply-later`): применяет только последний ожидающий |
| Сохранённое и не применённое (другое окно, ядро было недоступно, перезагрузка в паузе) | задача `sweep` раз в пять минут |
| Применять нечего (спека равна снимку применённого) — роутер не трогается | служба хоста `spec get --applied` |
| Отвергнутое ядром не повторяется, пока спека не изменится; «не состоялось» (ядро занято коннектором, остановил хук) повторяется | отпечаток отвергнутой спеки, исход службы `apply` (коды 1 и 3) |
| Исход и состояние для интерфейса | методы `autoapply_status`, `autoapply_now`, `autoapply_cancel` |
| Применили без нас — забыть отвергнутое | событие ядра `applied` |

## По умолчанию выключено

Решение О-11 не принято, поэтому плагин ничего не меняет в поведении каркаса, пока человек не включил настройку `enabled`:
в каркасе «Применить» — явное действие. Andromeda применяет сама, через 0,8 с тишины, и это остаётся: применение
идемпотентно и идёт под замком каркаса, второе применение той же спеки ничего не меняет. Включив плагин, человек получает
то же самое для случая, когда страницы нет.

## Какие точки API использует

| Точка API | Где |
|---|---|
| Манифест: `compat`, `permissions` (`splify2.hooks`), `i18n`, `rpc`, `splify2` | `plugin.json` |
| **Хук** `post_spec_set` (наблюдатель) | `hooks/spec-saved` |
| **Задача** `sweep` (`every: 5m`, `only_if: spec-present`) | `bin/sweep` |
| **События** `applied`, `failed` | `hooks/event` |
| **Хуки** `backup_sections`, `support_report`, `purge` | `hooks/backup`, `hooks/support`, `hooks/purge` |
| **Методы rpc** и псевдонимы | `bin/autoapply` |
| **Схема настроек**, значения через `s2_setting` | `settings.schema.json` |
| **Службы хоста**: `spec get [--applied]`, `apply`, `settings` | через `$SPLIFY2_HOST` |
| Рабочий каталог `STEER_PLUGIN_STATE` (метка ожидания, исход, отпечаток отвергнутого) | `lib/base.sh` |

## Настройки

| Ключ | Что |
|---|---|
| `enabled` | включить автоприменение (по умолчанию выключено) |
| `pause_s` | пауза после последней правки, секунд (по умолчанию 2) |
| `sweep` | применять сохранённое и не применённое раз в несколько минут (по умолчанию да) |

## Проверка

```sh
sh tests/autoapplymatch.sh   # хук, пауза, склейка правок, sweep, события, методы, архив
sh tests/hostmatch.sh        # служба spec get --applied
sh tests/pluginhygiene.sh    # граница API
sh /путь/к/plugin-sdk/tests/compat/run.sh plugins/autoapply
```
