# lang-ru — русский язык

Официальный плагин splify2 (`splify2-core-plugins`), `type: language`, ставится вместе с пакетом. Каркас splify2 и его
бэкенд написаны по-английски; этот плагин переводит их на русский и несёт русский словарь панели Andromeda.

## Что внутри

| Файл | Для кого | Формат |
|---|---|---|
| `i18n/core/ru.json` | каркас (базовый вид на LuCI JS) | «английская строка → перевод», подстановки `{имя}`; ключи — все строки `luci/.../core/strings.json` |
| `i18n/host/ru.json` | Andromeda | «`ns.key` → строка», подстановки `{0}`, `{1}`; ключи — список строк панели |
| `i18n/backend/ru.json` | бэкенд (rpcd, службы хоста, официальные плагины) | «код → текст», подстановки `{имя}`; код — `область.смысл` из вызова `fail_code` / `s2_fail_code` / `s2_t` ([splify2-api](https://github.com/splify2/plugin-sdk/blob/main/docs/splify2-api.md), «Тексты для человека») |
| `i18n/ru.json`, `i18n/en.json` | карточка плагина | `plugin.name`, `plugin.description` |

## Что меняется для человека

- **Каркас** запрашивает словари методом `i18n_get` (язык — по настройке LuCI, `auto` — язык браузера) и подставляет
  перевод. Без плагина каркас английский.
- **Бэкенд** отдаёт отказы и сообщения по-русски, когда язык LuCI русский, а при языке `auto` или не заданном — когда
  русский выбран в интерфейсе. Без плагина — по-английски.
- **Andromeda**: русский вшит в саму панель и от плагина не зависит. Словарь `host/ru.json` панель при русском языке не
  читает; он служит списком ключей и образцом для переводов на другие языки.

Выключенный или снятый плагин словари больше не отдаёт: каркас и тексты бэкенда становятся английскими, Andromeda
остаётся русской.

## Как проверяется

`tests/langmatch.sh`: словарь каркаса покрывает `strings.json` без лишних ключей и с теми же подстановками, словарь
Andromeda непуст по каждому ключу, настоящий `i18n_get` отдаёт словарь включённого плагина и не отдаёт выключенного,
`s2p lint --official` проходит. Совпадение словаря Andromeda со строками самой панели проверяет её репозиторий.
`tests/i18nmatch.sh`: словарь бэкенда покрывает ровно те коды, что есть в коде, подстановки совпадают, английский текст
вызова равен словарю `lang-en`; в стендах он же даёт русские тексты отказов (`S2_LANG=ru`).

Обновление словаря вместе со строками каркаса: `node tests/automatch.mjs --write-strings` пересобирает `strings.json`,
стенд называет непереведённые строки.

## Чего нет

Строки журнала (`logger`, stderr), вывод разработчика и сообщения шлюза `/cgi-bin/splify2-api` (плагин `desktop-api`:
отказ несёт код `gateway.*`, словари — свои, `i18n/backend` плагина) этим плагином не переводятся. Строки схем настроек
других плагинов лежат в их собственных словарях.
