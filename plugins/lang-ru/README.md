# lang-ru — русский язык

Официальный плагин splify2 (`splify2-core-plugins`), `type: language`. Каркас splify2 написан по-английски; этот
плагин переводит его на русский, а панель Andromeda получает от него русский словарь.

## Что внутри

| Файл | Для кого | Формат |
|---|---|---|
| `i18n/core/ru.json` | каркас (классический LuCI JS) | «английская строка → перевод», подстановки `{имя}`; ключи — все строки `luci/.../core/strings.json` |
| `i18n/host/ru.json` | Andromeda | «`ns.key` → строка», подстановки `{0}`, `{1}`; ключи те же, что в `ui/src/copy/ru.json` |
| `i18n/ru.json`, `i18n/en.json` | карточка плагина | `plugin.name`, `plugin.description` |

Каркас запрашивает словарь методом `i18n_get` (язык — по настройке LuCI, `auto` — язык браузера) и подставляет перевод в
`T()`; словарь Andromeda панель кладёт в память браузера (`registerHostDict`). Русский в Andromeda пока ещё вшит в код
(`ui/src/copy/ru.ts`), поэтому словарь `host/ru.json` служит ей эталоном и запасным вариантом; без плагина всё остаётся как
было.

## Как проверяется

`tests/langmatch.sh`: словарь каркаса покрывает `strings.json` без лишних ключей и с теми же подстановками, словарь
Andromeda совпадает с `ui/src/copy/ru.json`, настоящий `i18n_get` отдаёт словарь включённого плагина, `s2p lint --official`
проходит.

Обновление словаря вместе со строками каркаса: `node tests/automatch.mjs --write-strings` пересобирает `strings.json`,
стенд называет непереведённые строки.

## Чего нет

Тексты бэкенда (отказы методов `rpcd`, строки журнала) пока написаны по-русски в самом коде и этим плагином не
переводятся: в `splify2-api` нет механизма подстановки текстов бэкенда по словарю.
